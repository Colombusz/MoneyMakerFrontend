# MoneyMaker Frontend

React web app for budget tracking with partner co-budgeting. Offline-capable with background sync.

## Features

- **Offline-first** — Full functionality without internet, syncs on reconnect
- **Partner co-budgeting** — Invite partners, share budgets, track together
- **Real-time updates** — Live sync across all connected devices
- **Responsive** — Works on desktop and mobile browsers

## Tech Stack

- React 19 + TypeScript
- Vite
- Redux Toolkit
- Tailwind CSS
- Vitest + React Testing Library
